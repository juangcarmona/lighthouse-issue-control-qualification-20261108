# Lighthouse issue-control qualification

This isolated repository exercises the public issue-control SDK against the source-owned GitHub router and native workers. It contains no product application or deployment credentials.

Qualification distinguishes actual-user comment publication, typed source admission, worker execution and validated stage results. Refine and Propose are stage-only requests. Ordinary comments cannot resume a pending question. Duplicate and uncertain intents must reconcile through their original source records.

The fixture may publish proposal branches and reports. It does not delegate implementation, merge, release or deployment authority. Activation is recorded by source repository variables; installation alone does not enable work.
